# 🎮 reels - Automated Short Form Content Generation
reels is a Python app that creates story-driven reels with auto-generated voiceovers and subtitles. 🚀

## ✨ Features
 - 📚 AI-Generated Stories – Uses Mistral-7B to create unique short stories based on gameplay.
 - 🎣️ Natural Voiceovers – Converts stories to voice using Edge TTS.
 - 🎥 Video Processing – Merges voiceovers with gameplay footage using MoviePy.
 - 🔠 Auto-Generated Subtitles – Uses srt for speech-to-text subtitles.
 - 📂 Automated Workflow – Takes gameplay clips from assets/ and exports final videos to generated_content/.
 - 🔄 Random Video Selection – Automatically picks a random .mp4 file from assets/ for each run.
 - ♻️ Batch Generation – Supports generating multiple videos in one run using command-line arguments.

### Note
 - The example input is just 1 min long, but the real inputs when running the app need to be 10 mins or longer for optimal conditions.
